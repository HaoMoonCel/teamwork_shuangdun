# 去 AI 味设计规范

> 目标：让双墩刻符数字平台整体呈现「文博考古 · 古朴庄重 · 视觉舒适」的气质，
> 去除常见的 AI 产品感 / 科技 SaaS 感。适用于全站所有页面。

---

## 一、首页去 AI 味准则（既有约定，长期适用）

1. **拒绝玻璃拟态**：不滥用 `backdrop-blur`、半透明毛玻璃层叠。
2. **拒绝大量渐变与光效**：装饰性渐变、光晕、发光按钮一律克制；能不用就不用。
3. **减少装饰**：无粒子、无炫光、无多余插画；装饰元素（刻符线稿、印章）点到即止。
4. **重视可读性**：文字对比度优先，图片只作氛围衬底，绝不压过文字。
5. **文创配色**：纸色 `#F5F0E8`、深墨 `ink`、土红 `terracotta #B26A42`、深暖棕导航 `#33220F / #2E1E0F`。
6. **构图**：外边界规整、内部轻微错落的不对称布局，避免死板等宽网格。
7. **字体**：全站统一同一套无衬线；标题沉稳厚重，不花哨。

## 二、刻符识别页去 AI 味改造建议（追加于本文件末尾）

> 说明：以下为 2026-08-19 对「AI 智能识别」页面的评审建议，
> 尚未实施，供开发时逐步落地。仅改皮，不动接口与识别逻辑。

### 2.1 文案口吻（优先级最高，效果最大）

| 现状 | 建议 |
| --- | --- |
| 页面标题「AI 智能识别」 | 「刻符比对」/「字形寻源」；副标题「输入汉字或上传图像，比对最相似的双墩刻符」 |
| Tab「📝 文字输入 / 📷 图像上传」 | 去掉 emoji，改纯文字，或刻符风 SVG 线稿小图标 |
| 按钮「发送识别」 | 「开始比对」 |
| Loading「AI 正在生成刻符图… / AI 正在识别…」 | 「正在研读刻符… / 正在比对…」 |
| 「扩散模型逐张采样，4 张约需 9 秒」 | 「正在临摹候选字形，请稍候」 |
| 「识别结果 — 共 N 个匹配」 | 「比对结果 · 共 N 枚候选」 |
| 「识别置信度较低（top-1 62%）」 | 「字形相似度偏低，请点选最接近的一枚」 |
| 「⚡ 推理耗时 1234ms ｜ 以上为 AI 模型匹配结果」 | 去掉 ⚡ 与毫秒数，改「本结果基于字形比对模型，供研究参考」 |
| 空状态 🔍「等待识别」 | 印章/拓片意象 + 「待比对」 |
| 「重新生成」 | 「另拟一版」 / 「换一枚」 |

### 2.2 视觉弱化「SaaS 感」

1. **加载态**：spinner 转圈 → 缓慢呼吸的印章方块或拓片意象，比通用转圈古朴。
2. **结果卡**：加一点拓片/摹本质感（细边框、纸纹底），减少通用卡片列表的“后台感”。
3. **配色**：维持土红 / 米白 / 深棕，不加高饱和蓝紫。

### 2.3 涉及文件

- `src/pages/AIRecognition.vue`（标题、提示浮条）
- `src/components/ai/InputPanel.vue`（Tab、按钮）
- `src/components/ai/ResultPanel.vue`（空态/加载/结果文案、emoji、⚡ 耗时）
- `src/components/ai/GenerateResult.vue`、`ResultCard.vue`（结果展示口吻）
